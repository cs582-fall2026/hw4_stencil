## Data Download

Download this homework’s data [here](https://drive.google.com/drive/folders/1EjzAgaZYW-JQ5VgjwBQv285cE54b-OHS?usp=sharing).
You only need the three CSV files inside the `RNA-classification/` folder: `train.csv`, `val.csv`, and `test.csv`.

Place them directly inside this `data/` folder (not in a subfolder), so it looks like:

```text
homework4/
  data/
    train.csv
    val.csv
    test.csv
```
